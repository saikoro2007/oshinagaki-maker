# お品書きメーカー (Oshinagaki Maker)

> 🏮 **スマートフォンから手軽に作成・A4/B5縦書き印刷できる飲食店向けメニュー作成ツール**

飲食店（和食、居酒屋、焼き鳥、そば・うどん等）の現場で「パソコンをわざわざ厨房に持ち込むのが不便」「スマホから日替わりメニューや本日のおすすめをサッと作って印刷したい」というニーズに応えるWebツールです。

## 主な特徴

- 📱 **スマホ完全対応**: スマートフォンのブラウザから片手で操作可能
- 📜 **本格的な縦書き組版**: CSS `writing-mode: vertical-rl` による右から左へ流れる和風お品書き
- 🖨️ **スマホからワンタップ印刷**: `@media print` 最適化により、A4/B5用紙にジャストフィット（AirPrint / PDF保存対応）
- ✍️ **多彩な和風書体**: 毛筆風（筆文字）・伝統明朝・和風ゴシック対応
- 🏮 **豊富なジャンル別定番プリセット**: 串焼き、居酒屋一品、鮮魚、蕎麦・うどん、甘味などをワンタップ追加
- 💾 **自動保存 & バックアップ**: ブラウザ（LocalStorage）に自動保存。JSONエクスポート・インポート対応
- 🔒 **プライバシー安心**: 完全クライアントサイド動作（サーバーへのデータ送信なし）
